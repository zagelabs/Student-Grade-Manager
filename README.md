
# Student Grade Manager

A simple command-line application built with Python to manage students and their grades.

## Features

- Add students
- Add grades to students
- View a student's grades
- View all students and their grades
- Calculate a student's average
- Calculate the class average
- Validate grades between 0 and 20

## Technologies

- Python 3

## Concepts Practiced

- Variables
- Input and output
- Conditionals
- Loops
- Functions
- Lists
- Dictionaries
- String methods
- Basic input validation

## How to Run

Clone the repository:

```bash
git clone https://github.com/zagelabs/student-grade-manager.git
```

Enter the project folder:

```bash
cd student-grade-manager
```

Run the program:

```bash
python main.py
```
